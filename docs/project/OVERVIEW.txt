================================================================================
                    DOMPETKITA — PROJECT ARCHITECTURAL OVERVIEW
================================================================================

1. RINGKASAN PROYEK
--------------------------------------------------------------------------------
Nama Aplikasi : DompetKita
Tujuan        : Aplikasi manajemen dan pencatatan keuangan modern multi-akun 
                (multi-tenant) untuk kebutuhan personal, rumah tangga (keluarga), 
                maupun usaha kecil dengan fokus utama pada kecepatan loading 
                dan pengalaman mobile yang mulus.
Tech Stack    : - Framework : Laravel 13.x (PHP 8.2+)
                - UI Engine : Filament PHP v5.x (Livewire v4)
                - Tenancy   : Filament Multi-Tenancy (Tenant Model: Account)
                - Mobile UI : hammadzafar05/filament-mobile-preset
                - Auth & 2FA: Filament Breezy Plugin
                - Database  : MySQL / PostgreSQL / SQLite


2. PRINSIP ARSITEKTUR UTAMA
--------------------------------------------------------------------------------
1. No Database Enum Types (Tanpa Tipe ENUM di Database):
   - Seluruh kolom status/tipe/kategori disimpan sebagai `string(20)` atau `string(30)` 
     di level database untuk kompatibilitas penuh antar DBMS (MySQL, PostgreSQL, SQLite) 
     dan kemudahan migrasi.
   - Integritas data dan validasi opsi dikelola sepenuhnya di level aplikasi 
     menggunakan fitur resmi PHP 8.1+ Backed Enums (misal: `App\Enums\TransactionType`) 
     dan Eloquent Model Attribute Casting (`$casts`).

2. Performance-First & Fast Loading (Kecepatan Maksimal):
   - Database Indexing Optimal: Seluruh foreign key dan kolom pencarian/sorting 
     (`account_id`, `happened_at`, `status`, `slug`, `order`) diberi indeks.
   - Composite Indexing untuk Tenancy: Menambahkan indeks gabungan seperti 
     `(account_id, happened_at)` pada tabel mutasi untuk menjamin query riwayat 
     tetap kilat meskipun data transaksi mencapai jutaan baris.
   - Denormalisasi Terkontrol: Kolom `account_id` dipasang langsung di tabel operasional 
     (`budgets`, `transactions`, `transfers`, `debts`) untuk meniadakan query `JOIN` 
     bertingkat saat scoping tenant di Filament.
   - Filament Table Optimization: Menerapkan `deferLoading()` pada seluruh tabel, 
     menghindari query N+1, dan membatasi ukuran paginasi default (15-20 data per halaman).

3. Mobile-First Experience (Optimal di Ponsel):
   - Memanfaatkan plugin `hammadzafar05/filament-mobile-preset` yang menyediakan:
     * Bottom Navigation Bar untuk navigasi cepat yang mudah dijangkau ibu jari (*thumb-reach*).
     * Stacked Tables: Baris tabel bertransformasi rapi menjadi kartu di layar < 640px 
       tanpa perlu scroll horizontal.
     * Slide-over modal sebagai standar penginputan data agar alur pengguna tetap fokus.


3. ARSITEKTUR MULTI-TENANCY & HAK AKSES
--------------------------------------------------------------------------------
- Tenant Utama: `Account` (Akun Pembukuan).
  Satu user dapat memiliki banyak akun (misal: "Keuangan Pribadi", "Keuangan Rumah Tangga").
- Manajemen Anggota: `account_member`.
  Pemilik akun (`owner`) dapat mengundang user lain (`member` / `viewer`) 
  untuk mencatat atau memantau keuangan bersama.


4. SPESIFIKASI SKEMA DATABASE (NO DB ENUMS)
--------------------------------------------------------------------------------

--------------------------------------------------------------------------------
A. CORE & OTENTIKASI
--------------------------------------------------------------------------------

1. users (Bawaan Laravel + Breezy)
   - id                  : id (primary key)
   - name                : string
   - email               : string (unique)
   - email_verified_at   : timestamp (nullable)
   - password            : string
   - two_factor_secret   : text (nullable, Breezy 2FA)
   - two_factor_recovery : text (nullable, Breezy 2FA)
   - avatar_url          : string (nullable)
   - remember_token      : string (nullable)
   - timestamps

2. accounts (Tabel Tenant / Pembukuan)
   Deskripsi: Mencatat entitas pembukuan independen.
   - id            : id (primary key)
   - owner_id      : foreignId -> users.id (cascade on delete)
   - name          : string, index
   - slug          : string, unique (digunakan sebagai route tenant key)
   - currency_code : string(3), default('IDR') (mata uang pelaporan akun)
   - description   : text, nullable
   - timestamps
   - softDeletes

3. account_member (Tabel Pivot & Undangan Member Tenant)
   Deskripsi: Menghubungkan user ke akun beserta status dan hak aksesnya.
   - id               : id (primary key)
   - account_id       : foreignId -> accounts.id (cascade on delete)
   - user_id          : foreignId -> users.id, nullable (diisi saat user sudah terdaftar)
   - email            : string, index (email tujuan undangan)
   - invitation_token : string, nullable, unique (token untuk klaim undangan)
   - role             : string(20), default('member'), index 
                        (pilihan via PHP Enum: owner, member, viewer)
   - status           : string(20), default('invited'), index 
                        (pilihan via PHP Enum: invited, active, left, revoked)
   - invited_at       : timestamp, nullable, index
   - confirmed_at     : timestamp, nullable, index
   - left_at          : timestamp, nullable, index
   - revoked_at       : timestamp, nullable, index
   - timestamps
   - Constraint       : unique(account_id, email)

--------------------------------------------------------------------------------
B. MASTER DATA KEUANGAN
--------------------------------------------------------------------------------

4. wallets (Dompet / Rekening / Akun Kas)
   Deskripsi: Tempat penyimpanan saldo uang fisik maupun digital (Bank, E-Wallet, Kas Tunai).
   - id              : id (primary key)
   - account_id      : foreignId -> accounts.id (cascade on delete)
   - name            : string, index (contoh: "Bank UOB", "BCA", "Dompet Tunai")
   - slug            : string, index
   - currency_code   : string(3), default('IDR') (mendukung dompet multi-currency)
   - icon            : string, nullable
   - color           : string, nullable
   - current_balance : decimal(24, 2), default(0.00), index
                       (saldo riil saat ini, dikelola otomatis via DB Transaction)
   - allow_minus     : boolean, default(false), index (apakah saldo boleh bernilai minus)
   - timestamps
   - softDeletes
   - Constraint      : unique(account_id, slug, deleted_at)

5. categories (Kategori Pemasukan & Pengeluaran)
   Deskripsi: Klasifikasi transaksi keuangan per akun.
   - id         : id (primary key)
   - account_id : foreignId -> accounts.id (cascade on delete)
   - name       : string, index (contoh: "Gaji", "Makanan & Minuman", "Listrik")
   - slug       : string, index
   - type       : string(20), index 
                  (pilihan via PHP Enum: income, expense)
   - is_system  : boolean, default(false), index (kategori bawaan template)
   - icon       : string, nullable, index
   - color      : string, nullable, index
   - order      : unsignedBigInteger, default(0), index (urutan sorting tampilan)
   - status     : string(20), default('active'), index 
                  (pilihan via PHP Enum: active, inactive)
   - timestamps
   - softDeletes
   - Constraint : unique(account_id, slug, deleted_at)
                  unique(account_id, name, deleted_at)

--------------------------------------------------------------------------------
C. TRANSAKSI & MUTASI
--------------------------------------------------------------------------------

6. transactions (Mutasi Keuangan Utama)
   Deskripsi: Buku besar (ledger) seluruh pergerakan uang masuk dan keluar.
   - id                    : id (primary key)
   - account_id            : foreignId -> accounts.id (cascade on delete)
   - wallet_id             : foreignId -> wallets.id (restrict / cascade)
   - category_id           : foreignId -> categories.id, nullable
                             (wajib untuk 'transaction', null untuk 'transfer')
   - type                  : string(20), index 
                             (pilihan via PHP Enum: transaction, transfer)
   - direction             : smallInteger [1: Pemasukan, -1: Pengeluaran], index
   - amount                : decimal(24, 2), index (nominal transaksi, selalu positif)
   - wallet_balance_before : decimal(24, 2), index (snapshot saldo sebelum mutasi)
   - wallet_balance_after  : decimal(24, 2), index (snapshot saldo setelah mutasi)
   - category_name         : string, nullable (arsip denormalisasi untuk kecepatan history)
   - wallet_name           : string (arsip denormalisasi nama dompet)
   - happened_at           : timestamp, index (waktu transaksi riil terjadi)
   - note                  : text, nullable
   - timestamps
   - Performance Index     : index(account_id, happened_at) -> query rentang tanggal instan

7. transfers (Transfer Antar Dompet)
   Deskripsi: Header pemindahan dana antar dompet (Double-Entry Bookkeeping).
   - id                  : id (primary key)
   - account_id          : foreignId -> accounts.id (cascade on delete)
   - from_wallet_id      : foreignId -> wallets.id
   - to_wallet_id        : foreignId -> wallets.id
   - from_transaction_id : foreignId -> transactions.id (transaksi keluar, direction: -1)
   - to_transaction_id   : foreignId -> transactions.id (transaksi masuk, direction: 1)
   - fee_transaction_id  : foreignId -> transactions.id, nullable (transaksi biaya admin jika ada)
   - amount              : decimal(24, 2), index (nominal dana yang dipindahkan)
   - fee_amount          : decimal(24, 2), default(0.00), index (nominal biaya transfer)
   - happened_at         : timestamp, index
   - note                : text, nullable
   - timestamps
   - Performance Index   : index(account_id, happened_at)

--------------------------------------------------------------------------------
D. ANGGARAN (BUDGETING)
--------------------------------------------------------------------------------

8. budgets (Batas Pengeluaran Kategori)
   Deskripsi: Perencanaan alokasi pengeluaran per kategori per periode.
   - id               : id (primary key)
   - account_id       : foreignId -> accounts.id (cascade on delete)
   - category_id      : foreignId -> categories.id (cascade on delete)
   - max_amount       : decimal(24, 2), index (batas plafon anggaran, tidak boleh minus)
   - alert_percentage : unsignedSmallInteger, default(80) 
                        (persentase peringatan dashboard saat pengeluaran mendekati plafon)
   - period_type      : string(20), index 
                        (pilihan via PHP Enum: weekly, monthly, yearly)
   - period_start     : timestamp
   - period_end       : timestamp (harus > period_start)
   - timestamps
   - Constraint       : unique(category_id, period_start, period_end)
   - Performance Index: index(account_id, period_start, period_end)

--------------------------------------------------------------------------------
E. HUTANG & PIUTANG (DEBTS)
--------------------------------------------------------------------------------

9. debts (Pencatatan Pinjaman & Piutang)
   Deskripsi: Mencatat pinjaman yang harus dibayar (payable) atau piutang yang harus ditagih (receivable).
   - id                     : id (primary key)
   - account_id             : foreignId -> accounts.id (cascade on delete)
   - wallet_id              : foreignId -> wallets.id
                              (dompet penerima pencairan hutang atau sumber pengeluaran piutang)
   - initial_transaction_id : foreignId -> transactions.id, nullable
                              (transaksi otomatis di dompet saat hutang/piutang pertama dibuat)
   - counterparty_name      : string, index (nama orang/lembaga yang berpiutang/berhutang)
   - type                   : string(20), index 
                              (pilihan via PHP Enum: payable, receivable)
                              - payable    : Kita berhutang (kewajiban bayar)
                              - receivable : Orang lain berhutang ke kita (hak tagih)
   - initial_amount         : decimal(24, 2), index (nominal pokok pinjaman/piutang)
   - paid_amount            : decimal(24, 2), default(0.00), index (total yang telah dilunasi)
   - due_date               : timestamp, nullable, index (tenggat waktu jatuh tempo)
   - note                   : text, nullable
   - timestamps
   - softDeletes
   - Performance Index      : index(account_id, type)

10. debt_payments (Pembayaran Cicilan / Pelunasan Hutang-Piutang)
    Deskripsi: Riwayat pembayaran berkala yang memotong sisa hutang/piutang.
    - id             : id (primary key)
    - debt_id        : foreignId -> debts.id (cascade on delete)
    - transaction_id : foreignId -> transactions.id (transaksi mutasi kas dompet pembayaran)
    - amount         : decimal(24, 2), default(0.00) (nominal yang dibayarkan)
    - paid_at        : timestamp, index
    - timestamps

--------------------------------------------------------------------------------
F. PENDUKUNG (ATTACHMENTS)
--------------------------------------------------------------------------------

11. attachments (Lampiran File Polymorphic)
    Deskripsi: Menyimpan berkas bukti transfer, nota, struk, atau dokumen terkait.
    - id              : id (primary key)
    - attachable_type : string, index (contoh: App\Models\Transaction, App\Models\Debt)
    - attachable_id   : unsignedBigInteger, index
    - file_path       : text (lokasi file di storage)
    - mime_type       : string, index
    - size            : unsignedBigInteger, index (ukuran berkas dalam bytes)
    - timestamps
    - softDeletes
    - Performance Index: index(attachable_type, attachable_id)


5. ATURAN BISNIS & ALUR FINANSIAL (CORE RULES)
--------------------------------------------------------------------------------
1. Integritas Saldo Dompet (ACID Transaction):
   - Seluruh mutasi saldo dompet WAJIB dibungkus di dalam `DB::transaction()`.
   - Formula Update:
     `new_balance = current_balance + (direction * amount)`
   - Kolom `wallet_balance_before` dan `wallet_balance_after` selalu dihitung dan 
     disimpan di tabel `transactions` untuk audit trail yang presisi.

2. Alur Transfer Antar Dompet:
   - Transfer menghasilkan 1 row di tabel `transfers` dan 2 row di `transactions`:
     * Dari Dompet Asal : `direction: -1`, `type: 'transfer'`, `category_id: null`.
     * Ke Dompet Tujuan : `direction: 1`,  `type: 'transfer'`, `category_id: null`.
     * Biaya Admin (jika ada): 1 row transaksi pengeluaran tambahan (`direction: -1`).
   - Karena `category_id` bernilai null pada transfer, statistik Pengeluaran Riil 
     di dashboard bulanan TIDAK AKAN rusak/membengkak.

3. Alur Pencatatan Hutang & Piutang:
   - Saat membuat Hutang (Payable):
     * Saldo dompet penerima otomatis bertambah (`direction: 1`).
     * `initial_transaction_id` otomatis terisi menautkan transaksi tersebut.
   - Saat membuat Piutang (Receivable):
     * Saldo dompet sumber otomatis berkurang (`direction: -1`).
     * `initial_transaction_id` otomatis terisi menautkan transaksi tersebut.
   - Pembayaran cicilan (`debt_payments`):
     * Memotong saldo pokok (`paid_amount += payment.amount`).
     * Menghasilkan transaksi dompet sesuai aliran dana (bayar hutang = uang keluar, terima piutang = uang masuk).

4. Alur Multi-Tenancy & Undangan Member:
   - Tenant Model adalah `Account`.
   - Menggunakan relasi `HasTenants` bawaan Filament v5.
   - Jika calon anggota diundang:
     * Dibuat record di `account_member` dengan status `'invited'`.
     * Jika email sudah terdaftar, notifikasi/undangan muncul di panel.
     * Jika email belum terdaftar, sistem menyediakan link registrasi ber-token; 
       setelah akun dibuat, relasi tenant langsung terkonfirmasi.


6. PEDOMAN OPTIMISASI PERFORMA & LOADING (HIGH SPEED GUIDELINES)
--------------------------------------------------------------------------------
1. Filament UI & Data Loading:
   - Gunakan `->deferLoading()` pada semua Table Resource agar halaman terbuka instan 
     dan data dimuat secara asynchronously tanpa memblokir first-contentful-paint (FCP).
   - Tetapkan batas paginasi default yang efisien: `->defaultPaginationPageOption(15)`.
   - Hindari pemanggilan relasi N+1 di table column (gunakan `$record->wallet_name` 
     dari arsip denormalisasi atau eager loading resmi via `modifyQueryUsing(fn ($q) => $q->with(...))`).

2. Query & Composite Indexing:
   - Manfaatkan indeks komposit `(account_id, happened_at)` pada `transactions` 
     agar filter widget dashboard rentang tanggal bulanan/tahunan dieksekusi 
     dalam hitungan milidetik tanpa full-table scan.
   - Gunakan agregasi SQL murni (`selectRaw('SUM(...)')`) saat menghitung ringkasan 
     total balance dan cashflow daripada memanggil `.sum()` pada koleksi model Eloquent.

3. Mobile & Frontend Assets:
   - Plugin `hammadzafar05/filament-mobile-preset` meminimalkan elemen DOM yang berat 
     di viewport mobile.
   - Aktifkan route caching, config caching, dan view caching pada server production:
     `php artisan optimize`
   - Pastikan PHP OPcache aktif pada server PHP 8.2+.
